# HuskyCT submission guide

Submit these five items:

1. **GitHub repository URL:** https://github.com/br-ngu/classroom-survey . The repository is private: give the grader access through the course-approved process.
2. **Working application URL:** https://classroom-survey-6q4.pages.dev/ . Provide the instructor test email/password privately through the course-approved channel. Do not put credentials in GitHub or a public report.
3. **Development summary:** `docs/DEVELOPMENT_SUMMARY.md`. Review the suggested personal reflection and revise it to reflect your understanding. Convert to PDF or Word if HuskyCT requires that format.
4. **AI development history:** `docs/AI_DEVELOPMENT_HISTORY.md`. This is a Markdown summary permitted by the assignment, not a Cursor export.
5. **Evidence screenshots:** schema/tables; actual saved survey and question rows; actual stored response and answer rows; application results with counts and percentages. Hide anonymous browser tokens and credentials. Dashboard, editor, and QR presentation screenshots are useful extras.
